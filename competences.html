Les 6 compétences de première année

Chaque compétence est reliée à un projet principal afin de présenter clairement les traces et les apprentissages associés.

C1

Réaliser un développement d'application

Cette compétence consiste à concevoir, coder, tester et intégrer une solution applicative répondant à un besoin utilisateur.

Projet associé : le jeu Sokoban en langage C.

Acquisition : ce projet m'a appris à développer une application complète en console, avec déplacements, collisions, règles de jeu et conditions de réussite.

Projet Sokoban
C2

Optimiser des applications

Cette compétence correspond à la logique algorithmique : chercher une solution efficace, traiter les cas particuliers et améliorer un programme.

Projet associé : le problème du cavalier.

Acquisition : ce travail m'a fait utiliser une recherche en profondeur avec retour arrière pour trouver un parcours sur un échiquier, ce qui m'a aidé à mieux raisonner sur les graphes et les algorithmes.

Problème du cavalier
C3

Administrer des systèmes informatiques communicants

Cette compétence concerne la configuration d'un environnement informatique et l'utilisation d'outils système pour faire fonctionner une chaîne de traitement.

Projet associé : le projet Docker.

Acquisition : cette SAE m'a permis de travailler avec des conteneurs Docker, des scripts Bash/PHP et une chaîne de traitement automatisée pour transformer des fichiers.

Projet Docker
C4

Gérer des données de l'information

Cette compétence consiste à modéliser, interroger et exploiter des données afin de répondre à un besoin d'information précis.

Projet associé : le projet de création et modélisation d'une base de données.

Acquisition : cette SAE m'a fait pratiquer la modélisation relationnelle, la création d'un schéma de base et l'organisation de données exploitables.

Projet de base de données
C5

Conduire un projet

Cette compétence consiste à organiser un travail, définir les tâches, anticiper les besoins et produire des livrables compréhensibles.

Projet associé : le site web touristique dynamique.

Acquisition : ce projet m'a appris à travailler avec des besoins utilisateurs, une charte graphique, des délais et une organisation de groupe.

Site web touristique
C6

Collaborer au sein d'une équipe informatique

Cette compétence consiste à communiquer clairement, répartir le travail, écouter les autres et avancer ensemble vers un résultat commun.

Projet associé : le prototype d'application pour une boulangerie.

Acquisition : ce projet m'a permis de réfléchir à une application avec une vision collective, de discuter les choix d'interface et d'organiser les idées avant le développement.

Prototype boulangerie
