# Préparation de l'oral - Portfolio BUT Informatique

Durée attendue : 7 minutes.  
Support : le site portfolio.

## Objectif

Présenter le site sans expliquer la technique HTML/CSS. La partie la plus importante est la page Compétences : pour chaque compétence, je dois dire :

- le numéro de la compétence ;
- le nom exact du libellé ;
- une explication avec mes mots ;
- le projet qui m'a permis de commencer à l'acquérir.

## Plan minute par minute

### 0:00 - 0:35 - Introduction

Bonjour, je m'appelle Dylan Buanic et je suis étudiant en première année de BUT Informatique à l'IUT de Lannion.

Je vais présenter mon portfolio. Il est organisé en plusieurs pages : accueil, parcours, compétences, projets et contact. J'ai choisi d'associer un projet principal à chaque compétence pour que les preuves soient faciles à suivre.

### 0:35 - 1:10 - Profil, objectif et parcours

Sur la page d'accueil, je présente ma situation actuelle et mon objectif : trouver une alternance de 24 mois dans le développement logiciel, le développement web ou les bases de données.

Sur la page parcours, je présente ma formation en BUT Informatique, mon baccalauréat général, puis mes expériences. Biocoop m'a appris la rigueur et la communication, tandis que mon stage chez Worldline m'a permis d'observer une équipe informatique en contexte professionnel.

### 1:10 - 1:50 - Compétence 1

Compétence 1 : "Réaliser un développement d'application".

Avec mes mots, cette compétence signifie être capable de partir d'un besoin et de produire une application qui fonctionne. Il faut coder, tester, corriger et vérifier que les règles attendues sont respectées.

Le projet associé est le jeu Sokoban en langage C. Grâce à ce projet, j'ai travaillé les déplacements du personnage, les collisions, la logique des caisses et les conditions de réussite. Le code source est disponible depuis la page projets, ce qui sert de trace concrète.

### 1:50 - 2:30 - Compétence 2

Compétence 2 : "Optimiser des applications".

Pour moi, optimiser signifie améliorer la manière de résoudre un problème, choisir une stratégie adaptée et éviter de se bloquer dans des cas impossibles.

Le projet associé est le problème du cavalier. Il fallait réfléchir au tour du cavalier sur un échiquier, en utilisant une logique de graphe et de backtracking. Le dépôt GitHub du projet est lié sur le site et montre le travail réalisé.

### 2:30 - 3:10 - Compétence 3

Compétence 3 : "Administrer des systèmes informatiques communicants".

Cette compétence consiste à savoir utiliser et configurer un environnement informatique pour faire fonctionner des outils ensemble.

Le projet associé est la SAE 1.03 autour de Docker. Dans cette SAE, il fallait utiliser des conteneurs, des scripts Bash ou PHP, et une chaîne de traitement automatisée pour transformer des fichiers. Cela m'a fait travailler l'environnement système, Docker et l'automatisation, avec les différentes étapes du projet ajoutées comme traces sur le site.

### 3:10 - 3:50 - Compétence 4

Compétence 4 : "Gérer des données de l'information".

Avec mes mots, gérer des données signifie organiser des informations, les modéliser et les interroger pour répondre à un besoin précis.

Le projet associé est la SAE 1.04 de base de données. J'ai travaillé la modélisation, la création d'un schéma de base et l'organisation de données relationnelles. Le diagramme et les scripts ajoutés sur le site montrent ma progression dans la compréhension des bases de données.

### 3:50 - 4:30 - Compétence 5

Compétence 5 : "Conduire un projet".

Cette compétence consiste à organiser le travail, comprendre un besoin, respecter des contraintes et produire des livrables clairs.

Le projet associé est le site web touristique dynamique. Il fallait travailler en équipe, analyser les besoins, respecter une charte graphique, structurer les pages et gérer les délais. Le dépôt GitHub du site est lié sur le portfolio.

### 4:30 - 5:10 - Compétence 6

Compétence 6 : "Collaborer au sein d'une équipe informatique".

Pour moi, collaborer signifie communiquer, écouter les autres, répartir les idées et construire une solution commune.

Le projet associé est le prototype d'application pour une boulangerie. Ce projet m'a permis de réfléchir collectivement aux besoins, aux écrans et aux parcours utilisateurs. Le prototype Figma sert de trace, et j'ajouterai ensuite d'autres preuves quand le projet sera totalement finalisé.

### 5:10 - 6:20 - Page projets et preuves

Sur la page Projets, on retrouve les 6 projets dans le même ordre que les 6 compétences : Sokoban pour C1, le problème du cavalier pour C2, la SAE Docker pour C3, la base de données pour C4, le site web pour C5 et le prototype boulangerie pour C6.

Cette organisation permet de voir directement quelle preuve correspond à quelle compétence. Les SAE 1.03 et 1.04 ont maintenant leurs traces principales sur le site, tandis que certains projets gardent seulement un lien GitHub ou Figma quand c'est plus adapté.

### 6:20 - 6:45 - Contact et CV

La page Contact regroupe mon email, mon téléphone, mon LinkedIn et mon CV téléchargeable. Cela permet aux enseignants ou à une entreprise de retrouver facilement mes informations.

### 6:45 - 7:00 - Conclusion

Pour conclure, ce portfolio montre mon parcours et ma progression pendant la première année de BUT Informatique. Il me permet aussi de préparer mon objectif principal : continuer à progresser en alternance, sur des projets concrets en entreprise.

Merci pour votre attention.

## Conseils rapides

- Sur chaque compétence, respecter l'ordre : numéro, libellé, explication, acquisition par projet.
- Ne pas détailler la technique du site.
- Si le temps manque, raccourcir la partie parcours, pas les compétences.
- Garder un débit calme : les compétences doivent rester la partie la plus claire de l'oral.
